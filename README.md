DevQueiroz | Portfólio Interativo (Modo História)

Portfólio web interativo desenvolvido em formato scroll-telling para apresentar a marca DevQueiroz, contar minha trajetória na tecnologia e converter visitantes em clientes interessados em criação de sites e soluções digitais sob medida.

Visão Geral do Projeto

O projeto foi pensado para funcionar como vitrine principal no link da bio do Instagram (@devqueiroz), oferecendo uma experiência leve, responsiva e direta para empresários, profissionais liberais e negócios locais.

Principais Recursos

Modo História (Scroll-telling): navegação em 4 capítulos com animações suaves ao rolar a página e barra de progresso no topo.

Tema Claro e Escuro: alternância de tema com persistência no localStorage e respeito à preferência do sistema.

Vitrine de Cases Interativa: filtro por categoria e modal detalhado (Desafio, Solução e Impacto Comercial) para os projetos ArenaDev, NutriTech e EduAgent.

Simulador Rápido de Escopo: ferramenta onde o cliente escolhe o tipo de site e recursos desejados, visualiza o prazo estimado e envia o resumo direto para o formulário.

Gerador de Mensagem de Orçamento: formulário com validação que monta e copia automaticamente o briefing pronto para envio no Direct ou WhatsApp.

Tecnologias Utilizadas

HTML5 semântico

Tailwind CSS (via CDN)

JavaScript (Vanilla) para interatividade, observador de scroll, modal e simulador

Google Fonts (Montserrat, Inter e Fira Code)

SVG inline para a identidade visual da marca

Como Executar ou Publicar

Como o portfólio foi estruturado em um único arquivo (index.html), não há necessidade de build ou instalação de dependências.

Localmente

Clone este repositório ou baixe o arquivo index.html.

Abra o index.html diretamente no navegador (ou utilize a extensão Live Server no VS Code).

No GitHub Pages

Suba o arquivo index.html na raiz do repositório.

Acesse Settings > Pages no seu repositório do GitHub.

Em Branch, selecione main (ou master) e a pasta / (root).

Salve e aguarde alguns instantes para o link público ficar disponível.
